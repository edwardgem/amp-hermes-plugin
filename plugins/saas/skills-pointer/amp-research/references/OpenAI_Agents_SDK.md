# OpenAI Agents SDK

## Overview

- The OpenAI Agents SDK is a lightweight framework designed for building agents and multi-agent workflows powered by OpenAI’s API.
- It incorporates features for tracing agents, including sub-agent handoffs, model calls, and tool calls.

Source: [OpenAI Agents SDK Overview](https://docs.wandb.ai/weave/guides/integrations/agents/openai-agents-sdk)

## Core Features

- **Development Framework:** Provides the necessary tools for enabling quick and efficient agent development with minimal abstractions.
- **Traceability:** Offers built-in tracing capabilities to visualize and monitor agent runs.

Source: [OpenAI Agents SDK Documentation](https://openai.github.io/openai-agents-python/)
