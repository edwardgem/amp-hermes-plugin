# Model Context Protocol (MCP)

## Key Concepts

- The Model Context Protocol (MCP) is an open-source standard that facilitates connections between AI applications and external systems, allowing seamless integration.
- MCP is likened to a USB-C port, as it standardizes connections for various AI applications to access data sources, tools, and workflows.

Source: [Model Context Protocol Overview](https://modelcontextprotocol.io/docs/getting-started/intro)

## Significant Features

- **Structured Access:** MCP allows AI models to interact with databases, file systems, APIs, and other services in an organized manner.
- **Transport Mechanisms:** It supports various transport methods for flexibility across different environments.

Source: [Spring AI Reference](https://docs.spring.io/spring-ai/reference/api/mcp/mcp-overview.html)
